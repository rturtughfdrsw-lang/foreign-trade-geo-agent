# 真实 B2B 技术文章：独立商业质量验收场景

场景 `B2B-REAL-CNC-SELECTION-01`：`EVIDENCE_NOT_SUPPLIED / NOT_REVIEWED`。这是待 D08 确认的规范，不是已有正例。演示 P3、Mock writer、页数/字数/引用数或准入成功均不能代替。

## 真实任务候选

**针对一份已定义零件与生产要求，买家如何依据适用资料筛选 CNC 方案、识别需要供应商验证的条件、整理可审核询价 brief？**

须有依据/条件/步骤：输入收集→几何/工序筛选→机器/夹具/刀具与质量可达性核验→产能假设→安装条件→交付/验收→未决项。不能仅说“影响选型”或保证某型号合适。所有者先批准全部义务，再取材，不能凭已有材料反向删难点。

## 最小证据包（看覆盖，不定来源数量）

可为一份完整获授权厂家应用文档或多份互补资料，无固定数量门槛。每个采纳论断有确切 version/条件/原文位置；缺项标不足/待补，LLM 或 owner 身份不能补事实。

| 对象 | 至少实际内容 | 来源/适用性要求 |
|---|---|---|
| E01 应用 brief | 材料/几何/尺寸/重量、图纸版本/特征、公差/表面/检验、批量/组合/工时/换型/节拍、厂房/目的地范围；不适用项有理由 | 有权企业人员提供，保密/使用权明确；只代表该应用，不推行业普遍规律 |
| E02 筛选依据 | 几何/工序/装夹/可达性到候选类别的依据，适用/不适用、替代/多工序限制 | 适用厂家应用资料、技术负责人或专业来源，支持为何/如何判断而非类型列表 |
| E03 型号/工艺条件 | 设备版本/配置、实际引用行程/包络/载荷等参数、夹具/刀具/材料条件、精度口径/验证方法 | 受控规格/应用试验或专业依据；绑定型号/选项/测试条件，不把标称精度变零件质量保证 |
| E04 产能依据 | 周期/换型/可用时间定义、假设、实测或可复核计算链/不确定性，缺资料则列待验证 | 原测量/审核应用分析；数字/单位/计算有支持，不由目标产量推实际承诺 |
| E05 安装/交付 | 配置对应电源/空气/排放/承载/通行/环境、目的地、包装/文件/调试/验收责任 | 适用厂家安装/合同或需求资料；若实际论述法规/安全，另取当地当前官方依据并专业审核，不用演示句代替 |
| E06 来源与审核链 | 作者/发布者、ID/version/date、全文/span、权利/保密范围、专业审核者/适用领域、时效/重审、未决项 | 来源真实性/论断支持/任务完整分别审核；专业人判断适用性，owner 决定用途/目标/价值 |
| E07 冻结 Planning | 已认可题目/全部义务、合法匹配 Opportunity/Plan、实际 bounded input 的 P/S 及限制 | 上传但未合法进模型/实际 prompt 不计可消费证据；不重 Planning 替换签核输入 |

不要求为文章增加数字；若不讨论某类参数，先批准更窄但有实际依据的任务并冻结全部义务。不得因短自动拒绝，也不得因厂家原文自动放行。S 保持未验证分类；真实专业手册若无合适摄入契约，记录适配阻塞，不塞进 S 后抹去来源/范围。

## 独立预期与质量判断

1. 无适用 E01–E07 覆盖/真实审核不正常生成，不用演示六句预填 SUPPORTED；明确缺技术事实与未评分开。
2. 缺一项已认可义务即不充分，不删项/降营销文案。相关主题/引用存在/Verified 字样不等于支持。
3. 充分输入经未来 Gate 只允许 writer；生成后逐论断审来源、条件/数字/单位、因果、适配范围、全任务与增量。供应商承诺只用获授权适用第一方证据。
4. 同充分输入的坏输出：反转关系、错用型号参数、漏安装条件、装饰引用、不实保证，Draft 质量审核必须拒绝；生成前 Gate 不能检查未来输出。
5. 买家应能形成有依据的筛选/询价材料并明确供应商待确认项；仅列主题不能通过。排名/流量/询盘效果不在本技术质量结论内。
6. 后续离线验收用实际获授权材料和真实专业标签，分别验证机械准入及输出质量；收费模型/客户站抓取/WordPress 各自另授权，不包含发布。

所有者可决定目标/义务/价值和有权用途；专业来源/审核者支持技术适用性；技术实现负责契约合法、输入冻结、接入/保全。本场景当前没有实际材料、批准或实测结果。
