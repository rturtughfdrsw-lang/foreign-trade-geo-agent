# foreign-trade-geo-agent

## 项目目标

面向 B2B 外贸独立站的 SEO/GEO 自动化系统。项目将把网站诊断、AI 可见度数据、优化建议、内容规划和 WordPress Draft 创建串联为可追踪的固定工作流。

## 当前 MVP 范围

- 输入一个外贸独立站 URL。
- 获取网站和第三方工具数据，并转换为统一数据结构。
- 基于诊断生成优化建议与 content plan。
- 基于企业真实资料生成文章，并仅通过 WordPress REST API 保存为 Draft。
- 保存历史结果，以支持后续优化前后比较。

## 当前阶段

目前仅建立项目骨架与架构文档，未实现业务逻辑、第三方集成、数据库或 API 服务。

## 暂不包含的能力

- 自由决策型 LLM Agent。
- 自动发布 WordPress 内容。
- Voyage GEO、GEORank、GEOFlow 的集成。
- FastAPI 服务、PostgreSQL 持久化、LangChain 或 LLM SDK 集成。
